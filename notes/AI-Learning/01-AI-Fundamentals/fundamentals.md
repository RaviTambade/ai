### The overall evolution

**Read → See → Hear → Search → Summarize → Create → Think → Act → Build**

Or, from an application-development perspective:

**Data → ML → Vision → Speech → Search/RAG → Generative AI → Agents → AI-Native Applications**

This gives a natural **AI curriculum** from basic AI understanding all the way to building production-oriented intelligent applications.
