# 5️⃣ Routing

Real applications don't always follow one path. Consider:

        ┌─────────────┼─────────────┐

# 🧠 Chain vs Agent

This distinction is worth remembering.

### Chain

The developer defines the path.

```text id="t4f9j8"
A → B → C → D
```

### Agent

The system can dynamically choose the next action.

```text id="z9o0ls"
       Agent
      /  |  \
     A   B   C
         ↓
        D
```

**Chain = predefined workflow**
**Agent = dynamic workflow**

Don't use an agent when a simple chain is sufficient. An agent introduces more autonomy—and therefore more uncertainty.

Now each technology has a different responsibility.

**LLM** → Interpret, reason, and generate according to the application's design.

 
# 🔍 8️⃣ Observability

Here's something beginners often forget. Suppose the customer asks:  “Why was my claim rejected?”

The AI gives an incorrect answer.

What happened?
Did retrieval fail?
Did the wrong document get retrieved?
Did the tool return incorrect data?
Did the model misunderstand the context?
Did the prompt contain the wrong information?
Without observability:

**we don't know.**

A production AI system should provide visibility into:

```text id="q6p3cb"
User Request
     ↓
Intent
     ↓
Prompt
     ↓
Retrieved Documents
     ↓
Tool Calls
     ↓
Tool Results
     ↓
LLM Response
     ↓
Latency / Tokens / Errors
```

This is why: **Tracing + logging + evaluation** are not optional luxuries. They become part of AI engineering.
